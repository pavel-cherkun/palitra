# Палитра

Гиперказуальная логистика цветов. Тянешь ленты от цветных источников к приёмникам и собираешь заказы вида «3 оранжевых и 2 синих».

- **Белый смеситель:** два первичных → один вторичный (красный + жёлтый = оранжевый, жёлтый + синий = зелёный, красный + синий = фиолетовый).
- **Чёрный разделитель:** вторичный → два первичных.
- **Приёмник:** ждёт свой заказ. Кольцо вокруг заполняется, полное кольцо — конец игры. Чужой цвет закупоривает ленту.
- **Ресурсы:** клетки ленты, смесители, разделители, мосты (лента пересекает другую). Раз в неделю (45 с) выбираешь одно улучшение, поле растёт.

Бесконечный режим, счёт — сколько кружков доставлено.

## Управление

- Тянуть от источника, смесителя или разделителя — проложить ленту.
- Тап (или ПКМ) по ленте, смесителю или разделителю — убрать, ресурсы вернутся.
- Смеситель и разделитель — перетащить из нижней панели на поле.

## Запуск

Статика без сборки и зависимостей: `index.html`, `style.css`, `game.js`. Локально — любой сервер, например `python3 -m http.server`.

В консоли: `palitra.step(10)` прокручивает 10 секунд игры, `palitra.S` — состояние.

# Палитра

Гиперказуальная логистика цветов. Рисуешь ленты от цветных источников к приёмникам. Каждый приёмник ест один свой цвет и всё время голоден.

- **Белый смеситель:** два первичных → один вторичный (красный + жёлтый = оранжевый, жёлтый + синий = зелёный, красный + синий = фиолетовый).
- **Чёрный разделитель:** вторичный → два первичных.
- **Приёмник:** хочет один постоянный цвет. Кольцо голода вокруг растёт, каждый кружок его отодвигает, полное кольцо — конец игры. Со временем приёмники голодают быстрее. Чужой цвет закупоривает ленту.
- **Ресурсы:** клетки ленты, смесители, разделители, мосты (лента пересекает другую). Раз в неделю (45 с) выбираешь одно улучшение, поле растёт.

Бесконечный режим, счёт — сколько кружков доставлено.

## Управление

- **Кисть:** тянешь от любой клетки, и лента ложится по пути. Можно протянуть кусок и оставить хвост, потом продолжить с конца. Провёл по лежащей ленте — перекрасил её направление. Закончил на чужой ленте — влился в неё. Начал с середины ленты — развилка: кружки сами едут в ту ветку, где их цвет нужен, а если она занята — в другую. Прямо поперёк ленты кладётся мост, если он есть.
- **Ластик** (кнопка в панели или правая кнопка мыши): проводишь по клеткам, стираются только они. Ресурсы возвращаются.
- Смеситель и разделитель — перетащить из нижней панели на поле.

## Запуск

Статика без сборки и зависимостей: `index.html`, `style.css`, `game.js`. Локально — любой сервер, например `python3 -m http.server`.

В консоли: `palitra.step(10)` прокручивает 10 секунд игры, `palitra.S` — состояние.
